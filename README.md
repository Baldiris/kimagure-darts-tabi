# きまぐれダーツ旅

全国47都道府県・7エリアから行き先を抽選する旅のアプリです。最初の画面でエリアを選び、そのままダーツを投げられます。地域を選ぶと、県名つきの地域地図へ切り替わり、抽選中も地域地図を使います。都道府県を指定すると、47県それぞれの地図へ切り替わり、その県の代表の町を案内します。結果画面は当たった県だけを拡大して表示します。九州・沖縄は沖縄を別枠に表示します。結果・旅先の履歴・保存した旅先を別画面で見返せます。

ダーツはタップで投げられます。長押しするとパワーがたまり、離すと投げます。キーボードの Enter／Space でも同じ操作ができ、Escape で長押しを中止できます。矢は地図の選ばれた県に着地し、刺さって揺れる演出のあとに結果を表示します。パワーは飛行演出にだけ反映され、抽選確率は変わりません。動きを減らす設定では演出を短縮します。

スマホでは抽選／地図ボタンが画面下に固定されます。エリア・指定した県と最新の結果、最近30回の履歴、保存した町はブラウザに記録されます。保存した町は履歴の30回制限とは別に残ります。履歴は外部サーバーへ送信しません。Googleマップで目的地・観光スポット・飲食店を探せます。

## 開発

```sh
npm ci
npm run dev
```

## 公開

```sh
npm run build
```

生成される `docs/` をコミットしてください。GitHub Pages の公開元は `main` ブランチの `/docs` です。静的ファイルのみで動作し、APIキー・サーバーは不要です。

ビルド時に直前2世代のJS・CSSも残すため、GitHub Pagesの更新前のHTMLがキャッシュされていても画面を表示できます。

画像・地図・スクリプトは相対パスにしているため、プロジェクトURL配下でも読み込めます。地図の利用条件・出典は `public/assets/map-license.txt` と `map-source.txt` に記載しています。写真はAIで生成した旅のイメージです。

7つの地域地図と47都道府県の個別地図は同梱の日本地図から生成しています。更新時は `python scripts/build-region-maps.py` を実行してください。生成時に地域の県数・県コード、個別地図の47県の網羅と1県ずつの分割、地図内への配置、陸地内の着地点を検証します。
