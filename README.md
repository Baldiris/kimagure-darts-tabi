# きまぐれダーツ旅

全国1,741市区町村から次の旅先を抽選する、静的なWebアプリです。生成した旅の写真を入口に、全国・7地域・47都道府県で範囲を指定し、地域・県・町が順に止まるスロットを回せます。町の候補一覧と地域地図は必要なときに開けます。結果では当たった県の個別地図を表示し、Googleマップでその町を調べられます。

候補は市区町村単位で均等に抽選し、直前と同じ町が続けて出るのを避けます。政令指定都市は市単位、東京23区は区単位です。リールに流れる名前は演出です。動きを減らす設定では演出を短縮します。

最近30回の履歴と保存した町はブラウザに記録されます。保存した町は履歴の30回制限とは別に残ります。以前の版の履歴・保存は元の町を保ったまま移行します。APIキーや実行時サーバーは不要です。

## 開発・公開

```sh
npm ci
npm run check
npm run build
```

開発時は `npm run dev`、公開時は生成される `docs/` をコミットします。GitHub Pages は `main` ブランチの `/docs` を配信します。直前のJS・CSSも数世代保持し、更新前のHTMLがキャッシュされていても表示できるようにしています。

## データと地図

市区町村は Code for FUKUI / localgovjp（CC0）の2026-07-09更新データを使用しています。固定したコミットと加工内容は `public/assets/municipality-source.txt` に記載しています。更新時は `node scripts/import-municipalities.mjs /path/to/localgovjp.json` を実行してください。

7地域と47都道府県の地図は同梱の日本地図から生成しています。地図の出典と利用条件は `public/assets/map-source.txt` と `map-license.txt` に記載しています。地図更新時は `python scripts/build-region-maps.py` を実行してください。

`npm run check` で全候補の到達性、地域・県の絞り込み、連続重複の回避、旧履歴の移行と町ごとの保存を確認します。
