# きまぐれダーツ旅

全国1,741市区町村から行き先を抽選する旅のアプリです。全国・7エリア・47都道府県で絞れます。最初の画面でエリアを選び、スロットを回せます。地域を選ぶと県名つきの地域地図へ、都道府県を指定すると47県それぞれの地図へ切り替わります。候補数・検索できる候補一覧を表示し、直前と同じ町が続けて出るのを避けます。結果画面は当たった県だけを拡大して表示します。九州・沖縄は沖縄を別枠に表示します。結果・旅先の履歴・保存した旅先を別画面で見返せます。

スロットはボタンで回せます。地域・都道府県・市区町村が順に止まり、指定済みの範囲は最初から固定されます。回転中の町名は実際の候補一覧から表示し、選んだ地域・県と一致します。抽選そのものは選んだ範囲の全候補から市区町村単位で行います。動きを減らす設定では演出を短縮します。

スマホでは抽選／地図ボタンが画面下に固定されます。エリア・指定した県と最新の結果、最近30回の履歴、保存した町はブラウザに記録されます。保存した町は履歴の30回制限とは別に残ります。履歴は外部サーバーへ送信しません。Googleマップで目的地・観光スポット・飲食店を探せます。保存は市区町村ごとに独立して記録します。以前の47候補版の履歴・保存は元の町を保ったまま、新しい形式へ移行します。

## 開発

```sh
npm ci
npm run dev
```

## 公開

```sh
npm run build
```

生成される `docs/` をコミットしてください。GitHub Pages の公開元は `main` ブランチの `/docs` です。静的ファイルのみで動作し、APIキー・サーバーは不要です。

ビルド時に直前2世代のJS・CSSも残すため、GitHub Pagesの更新前のHTMLがキャッシュされていても画面を表示できます。

画像・地図・スクリプトは相対パスにしているため、プロジェクトURL配下でも読み込めます。地図の利用条件・出典は `public/assets/map-license.txt` と `map-source.txt` に記載しています。写真はAIで生成した旅のイメージです。

7つの地域地図と47都道府県の個別地図は同梱の日本地図から生成しています。更新時は `python scripts/build-region-maps.py` を実行してください。生成時に地域の県数・県コード、個別地図の47県の網羅と1県ずつの分割、地図内への配置、陸地内の着地点を検証します。

## 市区町村データ

Code for FUKUI / localgovjp（CC0）の2026-07-09更新データを使用しています。政令指定都市は市単位、東京23区は区単位で扱い、市とその行政区を重複させません。データの出典・固定したコミット・加工内容は `public/assets/municipality-source.txt` に記載しています。市区町村一覧を同梱するため、実行時のAPI呼び出しは不要です。

更新時は元の `localgovjp.json` を取得して `node scripts/import-municipalities.mjs /path/to/localgovjp.json` を実行してください。`npm run check` で全候補の到達性、地域・県の絞り込み、連続重複の回避、旧履歴の移行と町ごとの保存を確認します。
