# きまぐれダーツ旅

全国47都道府県・7エリアから行き先を抽選する旅のアプリです。最初の画面でエリアを選び、そのままダーツを投げられます。結果・旅先の履歴・保存した旅先を別画面で見返せます。

スマホでは抽選／地図ボタンが画面下に固定されます。エリアと最新の結果、最近30回の履歴、保存した町はブラウザに記録されます。保存した町は履歴の30回制限とは別に残ります。履歴は外部サーバーへ送信しません。Googleマップで目的地・観光スポット・飲食店を探せます。

## 開発

```sh
npm ci
npm run dev
```

## 公開

```sh
npm run build
```

生成される `docs/` をコミットしてください。GitHub Pages の公開元は `main` ブランチの `/docs` です。静的ファイルのみで動作し、APIキー・サーバーは不要です。

画像・地図・スクリプトは相対パスにしているため、プロジェクトURL配下でも読み込めます。地図の利用条件・出典は `public/assets/map-license.txt` と `map-source.txt` に記載しています。写真はAIで生成した旅のイメージです。
