THE RULE / 01

候補を決める基準

01 / 含める

市・町・村・東京23区

各自治体を1候補にします。離島の市町村も含みます。町内の地区、駅、観光施設は個別候補にしません。

02 / 重複を除く

政令指定都市は「市」で1件

市とその行政区を両方入れると同じ土地を二重に数えるため、指定都市の区は候補から外します。東京23区はそれぞれ独立した候補です。

03 / 抽選する

範囲内で各候補が等確率

人口・面積・観光地の数・交通の便では重み付けしません。全国で投げた場合、候補数の多い都道府県ほど選ばれる確率は高くなります。

データと確認結果

Code for FUKUI / localgovjp の2026年7月9日版を元にしています。ID・名称・位置の1,741件を照合し、IDや県内名称の重複、位置の欠落はありません。47都道府県別の件数は国土地理院の都道府県別一覧（2025年10月1日）と上記の6村・23区を調整して一致します。
