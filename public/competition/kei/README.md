# ケイ案 — 行先を、偶然にまかせよう。

プレミアムな旅のキャンペーンを意識した、写真と一投を同じファーストビューに収める案。車窓と実物のダーツを写した独自生成画像を使い、紙、深緑、朱色だけで組んでいます。ゲームセンター風の装飾は使いません。

## 体験

1. 全国・地域・都道府県から候補範囲を選び、件数を確認。
2. 「ダーツを投げる」で候補から一つを等確率に抽選。円盤とダーツの飛行を表示。
3. 県名・市区町村名の結果カードを表示し、Google マップの検索に進む。

候補データは `../data/destinations.json` から読み込みます。自治体の地理座標を持たないため、投擲アニメーションの着地点は実際の市区町村位置を表しません。

## レビューと修正

- **構成レビュー**：スマートフォンでは写真より先に操作を置き、最初の画面で範囲選択と投擲ができるように調整。投擲結果は画面幅を問わずカード全体が見える位置へスクロールしてフォーカス。
- **操作レビュー**：投擲中に地域を変更すると古い範囲の結果に見える問題を防ぐため、処理中は選択をロック。範囲変更時には古い結果を消す。飛行の記号をダーツ形の SVG に差し替え。小さな文字のコントラストを上げた。

`node --check` と Node VM で、全国 1,741 候補、県絞り込み、投擲中のロック、結果、Google マップ URL、古い結果の消去を確認。ローカルのブラウザ表示は環境のブラウザ URL 制限により実施できていません。
